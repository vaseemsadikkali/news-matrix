# 📰 Premium Real-Time News Matrix

A modern and responsive news web application built using HTML, CSS, and JavaScript that delivers real-time global and local news through the GNews API. The platform provides category-based news browsing, location-based search, dark mode support, and an interactive user experience.

## 🚀 Features

* Real-time news updates powered by GNews API
* Search news by city, state, or country
* Multiple news categories:

  * Breaking News
  * National News
  * International News
  * Local News
  * Business & Economy
  * Technology
  * Sports
  * Entertainment
  * Markets
* Dark Mode support
* Text-to-Speech article reader
* Interactive news article modal
* Responsive design for desktop, tablet, and mobile devices
* Modern Glassmorphism UI

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* GNews API
* Web Speech API
* Git & GitHub

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/vaseemsadikkali/news-matrix.git
```

2. Navigate to the project directory:

```bash
cd news-matrix
```

3. Open `index.html` in your browser.
